## 2025-03-01 - [Insecure Cross-Domain Cookie Leakage]
**Vulnerability:** The cookie sanitization scripts (`youtube.py` and `vimeo.py`) previously used insecure `in` string matching (e.g., `'youtube.com' in line`) to filter Netscape HTTP Cookie files. This resulted in two critical security flaws:
1) Cross-domain cookie leakage where adversarial domains like `evilyoutube.com` were incorrectly allowed.
2) Broken HTTPOnly processing, since cookies prefaced with `#HttpOnly_.youtube.com` were sometimes skipped or incorrectly parsed as generic `#` comments.
**Learning:** Netscape HTTP Cookie files require strict parsing. Filtering by simple substring matching in security contexts is dangerous and enables cross-domain evasion attacks. Additionally, `#HttpOnly_` is a special case directive within Netscape Cookie standard which must be correctly stripped and processed, unlike standard `#` comments.
**Prevention:** Always parse Netscape cookie file lines specifically using tab delimitation (`\t`). Specifically validate the domain column using suffix matching (e.g., `domain.endswith('.youtube.com')`) rather than substrings. Explicitly check for and strip `#HttpOnly_` before evaluating the domain to ensure valid secure cookies are retained while blocking malicious domains.
## 2025-03-02 - [YAML Injection in Template String Renderer]
**Vulnerability:** The `yaml_safe` function only escaped double quotes (`"` to `\"`) when rendering interpolated values into YAML frontmatter using PEP-750 template strings.
**Learning:** Escaping only double quotes in double-quoted strings is insufficient. If an attacker's string ends with a backslash (e.g., `value\`), the resulting escaped string becomes `value\\"`. The YAML parser treats `\\` as a literal backslash, leaving the subsequent `"` unescaped. This allows the attacker to break out of the string context and inject arbitrary YAML nodes. Additionally, unescaped newlines (`\n`) and carriage returns (`\r`) can also break the string context in some YAML parsers.
**Prevention:** When sanitizing values for double-quoted strings in YAML, always escape backslashes first (`\` to `\\`), followed by newlines, carriage returns, and finally double quotes. Replacing backslashes first is crucial to avoid double-escaping the backslashes introduced during the escaping of other characters.
## 2025-03-03 - [Insecure Cookie File Permissions]
**Vulnerability:** The cookie sanitization scripts (`youtube.py` and `vimeo.py`) wrote sensitive session cookies to the disk without applying restrictive file permissions. The files were created with default system permissions, which could allow other local users to read the session data.
**Learning:** Always enforce strict file permissions (e.g., `0o600` for owner read/write only) when handling sensitive credential or session files on disk to mitigate unauthorized local access on multi-user systems. It is also safer and more pythonic to use `pathlib.Path.chmod(0o600)` when dealing with `Path` objects rather than `os.chmod()` to prevent `NameError` if the `os` module is not imported.
**Prevention:** Use `cookies_path_obj.chmod(0o600)` after writing to the cookie file to restrict permissions to the owner.
